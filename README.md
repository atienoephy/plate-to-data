#  Wastebin - Food Wastage Tracker

> Turn daily food waste into weekly savings. A 10-second log that tells you exactly what to cook less of, and when.

## The Problem

Restaurants lose money to food waste but don't know where:
- Food goes to waste daily - overcooked, leftovers, spoiled
- No one tracks WHY it was wasted
- Owners lose money but can't point to the exact problem
- Spreadsheets don't work - too hard for busy staff during rush hours

##  The Solution

**A Simple Food Wastage Tracker Web App** built with HTML, CSS, and JavaScript.

### How It Works:

1. **Log Page** - Staff fills a form: Dish, Quantity, Reason, Date
2. **Dashboard Page** - App shows numbers and patterns automatically

### What the Dashboard Shows:
- Total Wasted This Week in kg
- Top 3 Wasted Items (e.g., Rice: 4.2kg)
- Top Reasons (e.g., Over-prepped, Spoiled)
- Table of All Logs for the week

## Built With

- HTML5
- CSS3 (Custom properties, Grid, Flexbox)
- Vanilla JavaScript (ES6+)
- localStorage (Browser storage)
